# Data Directory

This directory is reserved for reproducible public-source research.

- `raw/` contains unmodified public downloads and provenance sidecars.
- `processed/` contains cleaned, derived, or joined tables.
- No personal grievance text, restricted CPGRAMS records, or private citizen data belongs here.

Raw source files must not be edited in place. If a source is replaced, retain the old file and record the change in the provenance metadata.
