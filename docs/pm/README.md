# Public product-management documentation

This folder contains the public-facing product-management record for SewaPath.
The categories mirror how the product is operated:

- [Product](product/production-product-spec.md): citizen journey, boundaries,
  safety, and production gates.
- [Growth](growth/seo-analytics-launch.md): search, measurement, and launch
  operations.
- [Technical](technical/cloudflare-architecture.md): public deployment and
  data-flow boundaries.
- [Research](research/data-sources.md): public-source register and analysis
  method.

Private agent instructions, raw research material, internal reports, and design
reviews are intentionally kept outside the remote repository.
